# EduMentor – AI-Powered Adaptive Learning Companion

EduMentor is an interactive web application that acts as a personalised STEM tutor. It uses a large language model (LLM) and a knowledge graph to assess students, generate tailored explanations and practice questions, track progress, and adapt difficulty in real time.

## Features

- **Diagnostic Quiz** – assesses the student's current understanding and sets the starting level and topic
- **AI Explanations** – level-appropriate explanations generated by GPT-4o
- **Adaptive Practice Questions** – difficulty increases after 3 consecutive correct answers; decreases after 2 wrong answers
- **Instant Feedback & Hints** – encouraging feedback without giving away answers
- **Knowledge Graph** – models prerequisite relationships between topics, ensuring conceptual coherence
- **Progress Dashboard** – visual overview of mastered topics, difficulty, and performance per topic

## Architecture

```
Frontend (React/TypeScript + Vite)
        │
        │  REST API
        ▼
Backend (Python + FastAPI)
    ├── AI Orchestrator (OpenAI GPT-4o)
    ├── Knowledge Graph (JSON)
    └── Adaptive Recommender (rule-based)
```

## Quick Start

### Prerequisites
- Docker and Docker Compose
- OpenAI API key

### 1. Clone and configure

```bash
git clone https://github.com/aalandear-netizen/-EduMentor.git
cd -EduMentor
cp backend/.env.example .env
# Edit .env and add your OPENAI_API_KEY
```

### 2. Run with Docker Compose

```bash
docker-compose up --build
```

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API docs: http://localhost:8000/docs

### 3. Run locally (development)

**Backend:**
```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # add your OPENAI_API_KEY
uvicorn app.main:app --reload
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

## Running Tests

```bash
cd backend
pip install -r requirements.txt
pytest
```
